# ChatBox 公网访问

## 连接信息

- 服务器：`frp-oil.com`
- 端口：`15318`
- TLS：勾选
- 访问密码 / TOTP：留空
- 客户端：使用现有 portable ZIP，必须保留包内 `certs/ca.crt`

登录页默认只显示用户名和密码，公网地址已经预填好，一般直接登录即可。需要注册时点“注册”，昵称才会出现；填写后再点主按钮“注册”。如果地址被改过，点登录卡片下方的横向三点 `⋯` 展开服务器/端口/TLS：**“服务器”栏只填 `frp-oil.com`，不要写成 `frp-oil.com:15318`；端口单独填 `15318`**。把端口写进服务器栏会导致 `getaddrinfo failed`。客户端会用 QSettings 记住地址，之后可直接登录。局域网仍然可用 `192.168.2.240:9443`，适合在宿舍或同一网络内使用。

## 注册与限制

注册开放，不需要邮箱验证。为避免滥用，服务端限制：

- 每个 IP 每小时最多 20 次注册请求，全局每小时最多 100 次
- 每个 IP 最多 50 条连接，全局最多 500 条连接
- 共享校园网出口会被视为一个 IP；同一出口多人同时注册可能触发限制，请稍后再试

## 可用性与流量

SakuraFrp 免费额度约为 5 GiB/月、10 Mbps。额度耗尽、节点维护、宿舍断网或服务器所在笔记本睡眠/合盖时，公网入口会不可用；局域网不受公网隧道影响。服务器不承诺 24 小时在线，唤醒后 frpc 会自动重连。

公网传输会消耗隧道流量，请不要用它传大文件或长期挂机。重要内容请自行保留副本。

## 安全提醒

- 不要分享 SakuraFrp 访问 token、隧道 ID 或 `ca.key`；普通用户只需要上面的服务器、端口和 CA 证书。
- 如果客户端提示证书错误，确认使用的是分发包内未修改的 `certs/ca.crt`，不要关闭 TLS 校验；同时检查电脑时间是否正确。
- 这是个人服务器，请勿发送密码、证件号等敏感信息。
