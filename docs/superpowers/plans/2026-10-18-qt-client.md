# Qt 客户端 MVP 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 Windows Qt 5.15 客户端：原生 Winsock 网络线程、登录/注册、房间列表、群聊、私聊、最近会话、历史消息分页、心跳与断线重连。

**Architecture:** UI 全部在主线程；`NetworkThread` 继承 `QThread`，在独立线程中用原生 Winsock + `select` 收发，解析完整帧后通过队列信号发给主线程。协议复用服务端 `common/protocol`，UI 不直接操作 socket。

**Tech Stack:** Qt 5.15.2 Widgets、MinGW 8.1、C++17、Winsock2、qmake。

**Spec:** `docs/2026-10-18-linux-chatroom-design.md`

**Status:** 已实施并验证（2026-10-18）。

## Global Constraints

- 客户端禁止直连 MySQL。
- `winsock2.h` 必须在 `windows.h` 之前。
- socket 只在网络线程操作；UI 线程只发信号/队列帧。
- 所有网络字段大端；复用 `common/protocol`，禁止结构体直发。
- UI 使用纯文本渲染，内容做 HTML 转义。
- Token 只保存在内存；断线重连用 RESUME。
