# Chatroom 客户端品牌图标规格（app.ico / 托盘 / 大厅徽标）

> 日期：2026-10-19 · 状态：设计已定稿（用户已确认 B + R2）· 实施计划：`docs/superpowers/plans/2026-10-19-client-brand-icons.md`

## 1. 背景与目标

换肤完成后，三处图标仍是旧观感，用户要求重做：

1. **应用图标**：`resources/app.ico` 只有 64×64 单帧、淡青色人形剪影，任务栏/资源管理器发虚。
2. **托盘图标**：`ui/main_window.cpp` 用 Qt 自带 `SP_MessageBoxInformation`（蓝色 i，非品牌图形）。
3. **大厅徽标**：房间列表与聊天头部用 `avatarIcon(QString::number(id), id)`（绿圆 + 房间号「1」，语义无意义）。

## 2. 已确认决策

| 项 | 决策 |
|---|---|
| 应用图标 | **B · 实心气泡 + 镂空 C**：Coinbase 蓝 #0052FF 圆角方形底 + 白色实心气泡（含左下尾巴）+ 镂空蓝 C |
| 托盘图标 | 与 `:/app.ico` 同一资源（16/24px 走简化帧） |
| 大厅徽标 | **R2 · 品牌蓝底 + 白气泡**：`#0052FF` 圆 + 白色气泡（无字母），房间列表与聊天头部统一 |
| 小尺寸策略 | `.ico` 多帧：**256/128/64/48/32 用完整版（带 C），24/16 用简化版（纯气泡、无 C）**，避免 16px 下 C 糊成噪点 |
| 不改动 | 用户头像的「彩色圆 + 首字母」体系（含在线成员列表）保持不变；不改任何协议/服务端行为 |

设计原型（已渲染验证）：`.superpowers/brainstorm/11124-1792406202/content/app-icon.html`、`room-icon.html`。

## 4. 实施边界

- **应用图标**：新增 `tools/make_app_icon.ps1`（PowerShell + System.Drawing，无第三方依赖）生成多帧 `resources/app.ico`；HTTP 交付链不变（`resources.qrc` 已注册 `:/app.ico`，`app.rc` 的 `IDI_ICON1` 提供 exe 资源）。
- **托盘**：`ui/main_window.cpp` 托盘注册行改用 `QIcon(":/app.ico")`。
- **大厅徽标**：`core/avatar_utils.h/.cpp` 新增 `QImage roomAvatar(int size)`；`ui/main_window.cpp` 两处调用点（`selectRoom` 头部徽标、房间列表 item 图标）替换掉 `avatarIcon(...)`。
- 颜色单一来源：徽标蓝必须取 `core/ui_theme.h` 的 `theme::kAccent`，不得写死新颜色。

## 5. 验收

1. 测试（`tests/run_client_tests.ps1`）全绿，新增：
   - `brandAppIconExposesSizes`：`:/app.ico` 暴露且仅暴露 {16,24,32,48,64,128,256} 七个尺寸。
   - `roomAvatarIsBrandBadge`：36px 徽标中心为白（气泡）、边缘为 `theme::kAccent`、四角透明（圆形）。
   - `trayIconUsesBrandIcon`：`ui/main_window.cpp` 不再出现 `SP_MessageBoxInformation` 且包含 `:/app.ico`。
2. `build_client.ps1` 构建成功；运行后视觉核对：任务栏窗口图标、托盘图标、房间列表与聊天头部徽标（与原型 `room-icon.html` 一致）。
3. `.ico` 帧结构独立解析校验（脚本内 + PowerShell 头部解析），不依赖 Qt 也能确认 7 帧存在。
4. 零行为变更：不触碰网络/协议/数据库；用户头像体系不变。
