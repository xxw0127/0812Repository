# 消息功能：引用、@提及、撤回、搜索

**日期：** 2026-10-18

## 目标

补齐文本聊天的高频能力：引用回复、@提及提醒、2 分钟内撤回、历史消息搜索。

## 设计

- `messages` / `private_messages` 新增：
  - `reply_to_id`、`reply_sender_name`、`reply_content`（引用快照）
  - `recalled`（撤回占位）
- 发送协议在 content 后追加可选的引用字段；旧客户端不发时服务端按无引用处理。
- Push/History 在原有字段后追加引用字段和 `recalled`；旧客户端忽略尾部字段。
- 撤回命令 `0x0070`，房间广播/私聊推送；服务端限制发送者本人、2 分钟内。
- 搜索命令 `0x0080`，服务端 `LIKE` 搜索当前房间或私聊，返回结果列表。
- @提及首期按客户端昵称匹配：插入 `@昵称`，收到含 `@我的昵称` 的消息时托盘/任务栏提醒；不建服务端 mention 表。

## 已知限制

- 引用快照由发送端提供，服务端不重新校验被引用消息的可见性。
- @提及按昵称文本匹配，昵称重复/改名时可能误判。
- 搜索只返回结果列表，不支持双击定位到历史位置。
- 撤回只清理消息正文，引用该消息的历史快照仍可能保留原文。

## 验收

- 房间/私聊引用在发送、推送、历史中显示。
- 撤回后双方实时显示“消息已撤回”，历史重新加载仍为撤回状态。
- 搜索能按关键词找到房间/私聊消息。
- 服务端 ctest 4/4，客户端 18 测试通过。
