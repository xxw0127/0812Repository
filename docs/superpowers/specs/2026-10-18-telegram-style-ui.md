# 客户端浅色 Telegram 风格 UI

**日期：** 2026-10-18

## 目标

在不改变聊天功能的前提下，把 Qt 客户端从原生控件观感改成轻量、浅色、对齐统一的 Telegram 风格。

## 视觉规则

- 背景：`#E7EBF0`
- 面板：`#FFFFFF`
- 主色：`#3390EC`
- 自己气泡：`#EEFFDE`
- 对方气泡：`#FFFFFF`
- 主文字：`#1A1A1A`
- 次要文字：`#707579`
- 分隔线：`#E6E8EB`
- 圆角：8-18px
- 间距基准：8px
- 左侧会话栏 300px，右侧成员栏 220px
- 字体：Segoe UI / Microsoft YaHei UI

## 实现

- `resources/style.qss`：全局 QSS，覆盖窗口、面板、按钮、输入框、列表、滚动条、菜单、复选框。
- `resources/resources.qrc`：QSS、应用图标、搜索/设置/发送/退出/消息图标。
- `MainWindow`：三栏布局、会话头像、聊天头部头像、圆角输入栏、图标按钮。
- `LoginPage`：居中白色卡片、圆形 Logo、蓝色主按钮。
- 应用使用 Fusion style + 高 DPI 设置，保证 Windows 控件观感一致。

## 非目标

- 不复制 Telegram 的 logo、商标、表情或贴纸资源。
- 不重写 `QTextBrowser` 为虚拟列表；气泡圆角仍受 Qt 富文本限制。
- 暂不做深色模式。

## 验收

- 登录页和主窗口统一浅色风格。
- 列表头像、选中态、输入框、按钮对齐。
- 引用、撤回、搜索、@ 等既有功能仍可用。
- 客户端 18 个测试通过，应用构建成功。
